# Pi Agent Platform

Independent experimental platform built around upstream Pi, with Go service orchestration and PostgreSQL durable state.

This is a separate project from [Pan Agent](https://github.com/pym96/Pan-agent). Pan remains the completed TUI reference; no Pan runtime migration is implied.

Implementation is pending candidate migration and independent review. Current scope: durable task/session delivery and measured concurrent SSE connections. No production capacity or model-training claim.
