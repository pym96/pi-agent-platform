Human's goal is to learn inference infrastructure through real measurements; these are Agent-authored implementation and validation records, not claims that Human independently wrote or mastered the code. They are private learning material pending separate disclosure approval.

## A plausible fake version identity hid a real startup failure

The goal was to connect a fixed vLLM runtime to the existing serialized API. Builder's first test used the CUDA-tagged distribution string as the fake module version; it passed, and the initial independent source review missed the distinction. The first real container rejected the correct official runtime before engine construction. Actual wheel sources showed module0.8.5.post1 while package metadata was0.8.5.post1+cu118. The repair compared each identity to its own expected value and added an official-wheel CPU fixture with provenance; runtime/driver/model were not changed. The original failure cost55.169294118881226 device seconds and produced zero requests. Later real normal02 is separately identified. See [failed raw](builder-20261111/normal01-raw.tgz) and [independent failure review](regulator-20261111/NORMAL01-FAILURE-INDEPENDENT-REVIEW.v1.json). Next time, derive compatibility fixtures from the actual installed distribution before treating fake-module green as sufficient.

## Observability participates in the lifecycle it observes

The goal was to preserve actual GPU guard stdout/exit when it refused, rather than substitute a later snapshot. A thin logging wrapper initially appeared transparent, but independent R found that the Product's5s timeout could kill only the wrapper and leave its real nvidia-smi child. The wrapper needed its own shorter bounded child call, kill/wait, preserved raw bytes/status and explicit unknown on timeout. Four independent OS-process probes covered normal/non-UTF8/exit7, idle0, signal termination and actual timeout with the child gone. Preparing this after a short model GO consumed its window; Master held it before model execution and only issued normal02 after all inputs froze. See [HOLD](builder-20261114/NORMAL01-HOLD-RELEASE.v1.json) and [independent wrapper tests](regulator-20261114/NVML-WRAPPER-V2-INDEPENDENT-REVIEW.v1.json). Builder owns the first wrapper omission; Master owns signing before the observation seam was frozen; R found the defect. The lesson is to freeze observability and its cancellation behavior before starting the scarce compute window.

## HTTP failure, engine settlement and restart availability are different observations

The normal matrix tested direct disconnect and actual API loss during running native output. Raw abort ACK and native settlement establish logical execution cleanup; an HTTP error by itself would not. The explicit deadline run then returned generation_deadline with no generated output, followed by ACK/settled/ready. A separate fresh-engine recovery run successfully generated16 tokens. It does not prove that the same old slot resumed. SSE subscription disconnect on a durable platform task instead allowed that task to complete and replay; API restart marked an uncertain running task interrupted, cancelled its queued successor, blocked the old session and did not resend. See [normal review](regulator-20261114/B-NORMAL02-REAL-INDEPENDENT-REVIEW.v1.json), [deadline](regulator-20261114/B-DEADLINE01-REAL-INDEPENDENT-REVIEW.v1.json) and [recovery](regulator-20261114/B-RECOVERY01-REAL-INDEPENDENT-REVIEW.v1.json). Builder implemented and ran these mechanisms; Regulator independently checked original frames and ordering. These observations establish bounded functional behavior, not immediate GPU kernel preemption, multi-user capacity or throughput gains.
