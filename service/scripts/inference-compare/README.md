# Pi28 matched implementation comparison

Product opt-in measurement tool for [issue28](https://github.com/pym96/pi-agent-platform/issues/28), from accepted #24 exact28a2. This compares the entire serialized Transformers implementation with fixed vLLM single-sequence implementation. It does not isolate batching, claim a performance gain, change the default backend or authorize model use. See [candidate evidence/status](../../../docs/evidence/pi-engine-compare-20261114/README.md).

## Interface and original inputs

`prepare.py entries --source SOURCE --out NEWFILE` hashes every executing comparison/inference Python file and unchanged generic owned/native/driver seams. `prepare.py inventory --roots ROOT... --out NEWFILE` inventories apparent and allocated bytes, including directories and unreadable/missing roots as unknown. These are read-only CPU tools; server invocations need their own scoped GO.

`prepare.py tokens --arm A|B --model CACHED_MODEL --out NEWFILE` runs only the cached tokenizer under that arm's actual runtime. It produces expected IDs, never actual-generation truth. Combine the A/B `mapping` objects into `{ "A": {...}, "B": {...} }` only after preserving both original receipts/runtime identities. `plan.py --stage pilot --expected-inputs COMBINED --out NEWPLAN` fixes two warmups/six calibrations/recovery per arm. Formal/review plans additionally require `--calibration FILE` with `A_ns` and `B_ns`: exactly six actually successful send-to-valid-EOF durations from this pilot, plus provenance fields. Decimal50/ROUND_HALF_EVEN derives low/mid/high arrays. The complete formal matrix is A1/B1/B2/A2, six points per block,20 slots per point; all paired payloads are identical. `validate_frozen_plan()` rejects changed counts, payloads, order and offsets. Formal arrays and pilot provenance require independent R recomputation before formal GO.

## Measurement and replay

`client.py` uses strict accepted SSE semantics plus nonempty content, EOF and matched actual native IDs/usage. TF observation is opt-in with `TF_TOKEN_TRACE`: actual prepared input IDs, generate-entry diagnostic, and actual Streamer output IDs/status at settlement. Default-off observation changes no generation kwargs/template/decode/thread/memory/cancel behavior. Failure and cancellation have no invented successful terminal. vLLM native traces are reused unchanged. Prepared inputs map to app attempts; native call ordinals map to execution ordinals under the accepted single-slot app. Unprepared drops/rejections retain actual IDs null with a reason; expected IDs remain separate.

Open releases fixed absolute offsets with max32 outstanding requests; no client queue/retry. Closed refills only after response terminal up to C=1/4/8. A coroutine starting after its absolute deadline is a generator drop with no POST/sent timestamp. Actual invoked connection/response timeouts remain sent. Complete raw SSE chunks/timestamps, bodies, headers, EOF and transport failures are preserved per slot. After every point, require exact attempt counts, app execute/settled association, active0/queued0/ready, then timestamp confirmation on the client clock. That confirmation extends the formal throughput interval; the succeeding recovery probe is outside it. Unknown exchange/settlement stops with partial originals. Warmup/recovery/pilot failures cannot be silently replaced.

`recompute.py --plan PLAN --plan-sha256 HASH --stage-root RAW_STAGE --out NEWDIR` ignores producer classifications/metrics, reconstructs every frozen slot from raw protocol/native/drain files, rejects missing or duplicated failures and validates producer metrics against independent reconstruction. It writes CSV, per-repeat statistics and exploratory paired differences/ratios. P50/P95 use nearest rank on completed requests only, with all failed/drop counts retained. Native IDs supply actual output tokens; SSE chunks are not tokens and ITL is unmeasured. Open/closed timing and native/model clocks are never subtracted across processes.

For standalone scientific SVGs using the existing local plotting installation, run `/usr/bin/python3 plot.py --recomputed RECOMPUTED_JSON --stage-root RAW_STAGE --out NEWPLOTDIR` with `PYTHONDONTWRITEBYTECODE=1` and task-owned `MPLCONFIGDIR`. It uses standard matplotlib and no aiohttp/model dependency. Charts retain independent block labels, all20 planned-slot denominators, actual resource samples and missing/unknown gaps. Real curves require real raw stage receipts; CPU fixtures do not establish GPU performance.
